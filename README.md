# پادرا | Padra

پادرا یک اپلیکیشن Android برای بررسی سلامت، امنیت و بهینه‌سازی گوشی است.

## هدف نسخه اول
- داشبورد سلامت دستگاه
- اسکن امنیتی و بررسی ریسک‌ها
- پاک‌سازی فایل‌های قابل دسترس با تأیید کاربر
- بررسی باتری و فضای ذخیره‌سازی
- بررسی اپ‌های پرمصرف و مجوزهای حساس
- طراحی مینیمال فارسی با تم روشن و تیره

> Padra only performs actions allowed by Android APIs. Restricted system actions are surfaced as clear recommendations or deep-links to the relevant Android settings page.
